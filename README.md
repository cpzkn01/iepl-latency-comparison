## 先分清：IEPL专线、IPLC和CN2优化线路差在哪

IEPL（International Ethernet Private Line，国际以太网专线）和 IPLC（国际私有租用线路）都是点对点内网专线，数据传输不进公网；而 CN2 GIA、联通CUG、移动CMI 这类，属于“走公网但路由做了优化”的线路。这个差别直接体现在价格和体验两头。

价格差距相当直观。同样在香港、同样 100M 带宽，走电信CN2/联通CUG/移动CMI 优化线路的 VPS，500GB 流量 ¥45 就能拿下（比如 pia云 的香港 Speed Flex A），不到 MKCloud IEPL 入门款的四分之一。便宜的原因是共享公网链路。日常浏览、轻量建站，优化线路完全够用；差别主要体现在晚高峰——公网线路高峰期抖动和丢包会明显一些，内网专线因为点对点传输，延迟曲线基本是一条平线。

所以决策规则不复杂：流量小、预算紧、能接受偶尔波动，优化公网就够了；跑店铺后台、直播推流、实时通讯、远程桌面这类对延迟抖动敏感的业务，再考虑 IEPL/IPLC。MKCloud 的产品线里还有一档中间形态——上云互联IXP优化专线，优化入口加香港或日本 BGP 出口，¥158 起，适合“想要比 CN2 类产品稳一点，但不想付专线价格”的人。
